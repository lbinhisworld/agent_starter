# do1_smart_cto 虚拟机部署执行手册

## 1. 适用范围

本文档适用于把当前仓库中的前端和后端部署到一台新的 Linux 虚拟机。

默认假设：

- 系统为 `Ubuntu 22.04/24.04`
- 使用 `MySQL 8`
- 使用 `nginx`
- 使用 `pm2`

## 2. 安装基础软件

```bash
sudo apt update
sudo apt install -y git curl unzip build-essential nginx mysql-server
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
source ~/.bashrc
nvm install 24.14.0
nvm use 24.14.0
npm install -g pm2
```

检查版本：

```bash
node -v
npm -v
pm2 -v
mysql --version
nginx -v
```

## 3. 准备部署目录

```bash
sudo mkdir -p /srv/do1_smart_cto
sudo chown -R $USER:$USER /srv/do1_smart_cto
cd /srv/do1_smart_cto
```

## 4. 获取项目代码

```bash
git clone <your-repo-url> .
```

如果代码通过压缩包上传，也可以手工解压到 `/srv/do1_smart_cto`。

## 5. 初始化数据库

登录数据库：

```bash
sudo mysql
```

执行：

```sql
CREATE DATABASE do1_smart_cto CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'smart_cto_app'@'127.0.0.1' IDENTIFIED BY '<strong-password>';
GRANT ALL PRIVILEGES ON do1_smart_cto.* TO 'smart_cto_app'@'127.0.0.1';
FLUSH PRIVILEGES;
```

## 6. 配置后端

进入后端目录：

```bash
cd /srv/do1_smart_cto/backend
```

创建 `.env`：

```env
NODE_ENV=production
PORT=3000
DATABASE_URL=mysql://smart_cto_app:<strong-password>@127.0.0.1:3306/do1_smart_cto
```

安装与构建：

```bash
npm install
npm run prisma:generate
npx prisma db push
npm test
npm run build
```

启动后端：

```bash
pm2 start npm --name smart-cto-backend -- start
pm2 save
pm2 startup
```

检查后端：

```bash
curl http://127.0.0.1:3000/health
curl http://127.0.0.1:3000/openapi.json
```

## 7. 配置前端

进入前端目录：

```bash
cd /srv/do1_smart_cto/frontend
```

创建 `.env.production`：

```env
VITE_BACKEND_API_BASE_URL=https://<your-domain-or-ip>/api
VITE_API_URL=<company-analysis-api>
VITE_VALUE_STREAM_API_URL=<value-stream-api>
VITE_DEEPSEEK_API_KEY=<deepseek-key>
VITE_DEEPSEEK_API_URL=https://api.deepseek.com/v1/chat/completions
VITE_DEEPSEEK_MODEL=deepseek-chat
```

安装与构建：

```bash
npm install
npm run build
```

## 8. 配置 Nginx

创建配置文件：

```bash
sudo nano /etc/nginx/sites-available/do1_smart_cto
```

参考配置：

```nginx
server {
    listen 80;
    server_name <your-domain-or-ip>;

    root /srv/do1_smart_cto/frontend/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:3000/api/;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /health {
        proxy_pass http://127.0.0.1:3000/health;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
    }
}
```

启用配置：

```bash
sudo ln -s /etc/nginx/sites-available/do1_smart_cto /etc/nginx/sites-enabled/do1_smart_cto
sudo nginx -t
sudo systemctl reload nginx
```

## 9. HTTPS

如果已经有域名：

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d <your-domain>
```

## 10. 验收检查

部署完成后至少确认：

- `http://127.0.0.1:3000/health` 正常
- `http://127.0.0.1:3000/api-docs` 正常
- 前端首页可打开
- 首页创建案例可成功调用后端
- 问题详情页可读取 `/api/problem-cases/:id`
- 数据库中可看到 `problemcase` 和 `problemcasemessage` 表

## 11. 常用运维命令

查看后端：

```bash
pm2 list
pm2 logs smart-cto-backend
pm2 restart smart-cto-backend
```

查看 Nginx：

```bash
sudo systemctl status nginx
sudo nginx -t
```

查看数据库：

```bash
mysql -u smart_cto_app -p -h 127.0.0.1 do1_smart_cto
```

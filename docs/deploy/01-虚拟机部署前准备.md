# do1_smart_cto 虚拟机部署前准备

## 1. 目标

本文档用于在运维提供虚拟机后，提前确认部署前置条件、软件清单、网络要求和目录规划。

当前目标不是立即安装，而是先把部署条件准备齐，待你确认后再执行安装。

## 2. 推荐虚拟机规格

- 操作系统：`Ubuntu 22.04 LTS` 或 `Ubuntu 24.04 LTS`
- CPU：`2 vCPU` 起步，推荐 `4 vCPU`
- 内存：`4 GB` 起步，推荐 `8 GB`
- 磁盘：`40 GB` 起步，推荐 `80 GB`
- 网络：允许访问公网，用于 `apt`、`npm` 和模型 API

## 3. 服务器软件清单

以下软件建议安装在同一台虚拟机：

- `git`
- `curl`
- `unzip`
- `build-essential`
- `nginx`
- `MySQL 8.x`
- `nvm`
- `Node.js 24.14.x`
- `pm2`

推荐优先组合：

- Web 服务器：`nginx`
- 数据库：`MySQL 8`
- Node 版本：`24.14.x`
- 进程守护：`pm2`

## 4. 项目部署结构

建议统一放在：

```text
/srv/do1_smart_cto/
  frontend/
  backend/
```

前端构建产物建议路径：

```text
/srv/do1_smart_cto/frontend/dist
```

## 5. 端口与网络要求

- 对外开放：`80`、`443`
- 后端内部监听：`3000`
- 数据库内部监听：`3306`

建议策略：

- `nginx` 对外暴露 `80/443`
- Node 后端仅监听 `127.0.0.1:3000`
- 数据库仅本机访问，不暴露公网

## 6. 域名与 HTTPS

推荐准备：

- 一个正式域名，或至少一个可访问的测试域名
- HTTPS 证书，推荐使用 `certbot`

如暂时没有域名，可先使用服务器 IP 做内网/测试部署；正式上线前再补 HTTPS。

## 7. 应用配置项

### 7.1 后端

后端最少需要：

```env
NODE_ENV=production
PORT=3000
DATABASE_URL=mysql://<db_user>:<db_password>@127.0.0.1:3306/do1_smart_cto
```

### 7.2 前端

前端最少需要：

```env
VITE_BACKEND_API_BASE_URL=https://<your-domain>/api
```

如果前端页面仍需使用现有外部接口，可继续补充：

```env
VITE_API_URL=<company-analysis-api>
VITE_VALUE_STREAM_API_URL=<value-stream-api>
VITE_DEEPSEEK_API_KEY=<deepseek-key>
VITE_DEEPSEEK_API_URL=https://api.deepseek.com/v1/chat/completions
VITE_DEEPSEEK_MODEL=deepseek-chat
```

## 8. 部署前检查清单

运维需先提供：

- 虚拟机 IP
- SSH 登录账号
- SSH 端口
- 是否允许 `sudo`
- 操作系统版本
- 是否已有域名
- 是否允许安装 `nginx`、`MariaDB`、`Node.js`
- 是否需要走公司代理

你这边需确认：

- 项目部署目录是否采用 `/srv/do1_smart_cto`
- 数据库与应用是否部署在同一台虚拟机
- 是否立即配置 HTTPS
- 生产环境使用 `MySQL 8`
- 前端是否继续直连外部分析接口
- DeepSeek 生产 Key 是否已经准备

## 9. 当前建议

建议第一阶段采用：

- 单机部署
- `nginx + frontend dist + Node backend + MySQL 8`
- 先跑通内网访问和健康检查
- 确认功能正常后再接域名与 HTTPS

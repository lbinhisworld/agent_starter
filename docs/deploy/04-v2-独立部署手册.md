# Smart CTO v2 独立部署手册

> 把 `feat/simplify-customer-detail-page` 分支独立部署到服务器 `/qiqiao/do1_smart_cto_v2`。
> 不涉及 v1，不做灰度，不做回滚。

---

## 第一步：安装基础软件（如果服务器还没有）

```bash
sudo apt update
sudo apt install -y git curl unzip build-essential nginx mysql-server

# Node.js
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
source ~/.bashrc
nvm install 24.14.0
nvm use 24.14.0

# PM2
npm install -g pm2
```

---

## 第二步：创建数据库

```bash
sudo mysql
```

```sql
CREATE DATABASE IF NOT EXISTS do1_smart_cto_v2
  CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

CREATE USER IF NOT EXISTS 'smart_cto_v2_app'@'127.0.0.1'
  IDENTIFIED BY '你的强密码';

GRANT ALL PRIVILEGES ON do1_smart_cto_v2.*
  TO 'smart_cto_v2_app'@'127.0.0.1';

FLUSH PRIVILEGES;
EXIT;
```

验证：

```bash
mysql -u smart_cto_v2_app -p -h 127.0.0.1 do1_smart_cto_v2 -e "SELECT 1;"
```

## 第三步：拉取代码

```bash
sudo mkdir -p /qiqiao/do1_smart_cto_v2
sudo chown -R $USER:$USER /qiqiao/do1_smart_cto_v2

git clone -b feat/simplify-customer-detail-page \
  https://git.qiweioa.com.cn/liuhaitao/do1_smart_cto.git \
  /qiqiao/do1_smart_cto_v2
```

## 第四步：配置后端

编辑 `/qiqiao/do1_smart_cto_v2/backend/.env`：

```env
NODE_ENV=production
HOST=0.0.0.0
PORT=3099
DATABASE_URL=mysql://smart_cto_v2_app:你的强密码@127.0.0.1:3306/do1_smart_cto_v2
JWT_SECRET=换成一个随机长字符串
JWT_EXPIRES_IN=30d
```

> 生成随机密码：`openssl rand -base64 24 | tr -d '/+=' | head -c 32`


## 第六步：启动后端

```bash
cd /qiqiao/do1_smart_cto_v2/backend

pm2 start npm --name smart-cto-v2 -- start
pm2 save
```

验证：

```bash
# 等几秒让服务启动
sleep 3

curl http://127.0.0.1:3099/health
# 预期返回包含 "ok": true

curl http://127.0.0.1:3099/api-docs
# 预期返回 OpenAPI 文档
```

如果健康检查失败，看日志：

```bash
pm2 logs smart-cto-v2 --lines 30
```

## 第七步：配置前端

前端是**纯静态文件**（无构建步骤），只需修改 `config.local.js`。

编辑 `/qiqiao/do1_smart_cto_v2/frontend/config.local.js`：

```javascript
window.APP_CONFIG = window.APP_CONFIG || {};
window.APP_CONFIG.MODE = 'online';
window.APP_CONFIG.BACKEND_API_URL = '/api';
```

> 如果 Nginx 和后端在同一台机器，`/api` 会被 Nginx 反向代理到后端。
> 如果是局域网直接访问后端，改为 `http://服务器IP:3099/api`。

---

## 第八步：配置 Nginx

创建 `/etc/nginx/conf.d/smart-cto-v2.conf`：

```bash
sudo tee /etc/nginx/conf.d/smart-cto-v2.conf > /dev/null <<'EOF'
server {
    listen 80;
    server_name _;   # 改为实际域名或 IP

    root /qiqiao/do1_smart_cto_v2/frontend;
    index index.html;

    # 前端路由 — 所有页面走 index.html
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:3099/api/;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 健康检查
    location /health {
        proxy_pass http://127.0.0.1:3099/health;
    }
}
EOF
```

启用：

```bash
sudo nginx -t && sudo systemctl reload nginx
```

## 第九步：配置 AI（部署后执行）

> AI 配置接口需要登录后才能调用，先拿 JWT Token 再配置。

```bash
# 1. 登录获取 Token（默认管理员 root / root）
TOKEN=$(curl -s -X POST http://127.0.0.1:3099/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"root","password":"root"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin).get('token',''))")

echo "Token: $TOKEN"

# 2. 用 Token 写入 DeepSeek 配置（不要写在前端文件里）
curl -X PUT http://127.0.0.1:3099/api/ai/config \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "apiKey": "你的DeepSeek Key",
    "apiUrl": "https://api.deepseek.com/v1/chat/completions",
    "model": "deepseek-v4-flash"
  }'
```

验证 AI 配置：

```bash
curl -H "Authorization: Bearer $TOKEN" http://127.0.0.1:3099/api/ai/config
```

# FE-20260411-04 · 冻结轻混淆策略与禁止项

## 1. 任务元数据

- 任务编号：`FE-20260411-04`
- Phase：`1A`
- owner：`frontend`
- 优先级：`P0`
- 状态：`completed`

## 2. 任务目标

- 明确本专项只做轻混淆，不做重混淆。
- 冻结可接受的轻混淆策略与显式禁止项。
- 保证 build/minify 后仍可调试、可回归、可回滚。

## 3. 当前事实

- 浏览器端混淆只能提高逆向成本，不能承诺源码保密。
- 高强度混淆会直接增加运行时风险、回归成本和定位成本。
- 本专项的核心价值在工程化合同，而不是追求极限混淆强度。
- `FE-20260411-02` 已冻结 A 线只对 legacy bundle 范围做处理，外置配置、HTML 直连脚本与 `frontend-vue` 已产出资源不能被一并拉进混淆。
- `FE-20260411-03` 已冻结 `SmartCto.*`、`window.APP_CONFIG` 与 compat 双挂等桥接面，轻混淆必须建立在这些公开契约不漂移的前提上。

- 对调试、回归、回滚影响的约束说明。

## 5. Out Of Scope

## 7. 实施说明

1. 已把“轻混淆”目标限定为提升阅读与逆向成本，不承诺源码保密。
2. 已区分允许项、默认关闭项与显式禁止项，优先保护可调试、可回归、可回滚。
3. 已冻结轻混淆只作用于 A 线 bundle 范围，不覆盖外置配置、HTML 直连脚本、CDN 与 `vue-auth-assets`。
4. 已把本卡和保留名合同拆开：本卡只定义强度与禁用边界，具体白名单留给 `FE-20260411-05`。

### 7.1 轻混淆定义

| 项 | 固定口径 |
| --- | --- |
| 目标 | 提高阅读成本、降低直接可读性、压缩公开 bundle 的结构可见度 |
| 不承诺 | 不承诺前端源码保密、不承诺抵御专业逆向、不承诺替代后端鉴权或权限控制 |
| 前提 | 必须先完成 bundle + minify，再叠加轻混淆；若 minify 都未稳定，不得先上混淆 |
| 验收导向 | 混淆后仍能完成既定 smoke、运行时证据采集、问题定位与整包回滚 |

### 7.2 允许项

| 类别 | 允许范围 | 备注 |
| --- | --- | --- |
| 标识符压缩 | 仅对 A 线 bundle 内部私有局部变量、内部函数名、临时中间名做轻度改名 | 前提是不触及保留名合同 |
| 字符串 / 字面量轻度处理 | 仅允许不改变运行时语义、不会影响调试与报错定位的轻度处理 | 默认保守；若需启用必须能证明不影响回归 |
| 输出压缩配合 | 与 minify 配合做 bundle 级结构压缩 | 以可运行、可回归为先，不追求极限体积 |
| source map 策略 | 可选择生产关闭公开 source map，但需保留内部定位手段 | 是否公开 map 不等于允许重混淆 |

### 7.3 默认不做的项

| 类别 | 默认口径 |
| --- | --- |
| vendor / CDN | 默认不做 vendor 混淆；CDN 外链维持现状 |
| HTML / CSS | 默认不做入口 HTML 与样式层混淆处理 |
| `vue-auth-assets/**` | 默认不纳入 A 线轻混淆范围 |
| `config.js` / `config.local.js` / `js/auth-runtime.js` | 默认保持独立与可读，不进入混淆 |
| 报错文本 / 关键用户文案 | 默认不做语义级改写，避免定位困难和文案漂移 |

### 7.4 显式禁止项

| 禁止项 | 原因 |
| --- | --- |
| control-flow flattening / 控制流扁平化 | 显著增加运行时与调试风险，不符合轻混淆边界 |
| self-defending / 自保护 | 会影响调试、回滚与二次排障 |
| dead-code injection / 死代码注入 | 增加包体和不可预测性，收益不成比例 |
| debug protection / 禁调试保护 | 直接破坏线上问题定位与验收 |
| domain lock / 浏览器环境锁定 | 引入额外环境耦合，和部署稳定性目标冲突 |
| string array rotation / 高频运行时解码依赖 | 易造成性能与调试问题，超出首批可接受风险 |
| 改写公开桥接名 | 包括 `SmartCto.*`、`window.APP_CONFIG`、compat 双挂、HTML 直连入口名，一律禁止 |
| 将外置配置并入 bundle 再混淆 | 破坏部署与环境替换合同 |
| 对第三方 CDN 脚本做二次封装改写 | 增加不可控变量，超出本专项范围 |

### 7.5 适用范围边界

| 对象 | 是否允许进入轻混淆 | 说明 |
| --- | --- | --- |
| A 线 legacy bundle | 允许 | 本卡唯一主要作用对象 |
| `config.js` / `config.local.js` | 禁止 | 必须保持外置 |
| `js/auth-runtime.js` | 禁止 | 保持多入口直连脚本 |
| HTML 入口文件 | 禁止 | 不做 HTML 级混淆 |
| `vue-auth-assets/**` | 禁止 | 属于 `frontend-vue` 产物链，不在 A 线轻混淆范围 |
| 第三方 CDN 外链 | 禁止 | 保持外链现状 |

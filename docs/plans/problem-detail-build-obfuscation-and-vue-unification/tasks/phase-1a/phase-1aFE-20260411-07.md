## 2. 任务目标

## 3. 当前事实

- 详情页公开入口、配置文件、静态资源与 bundle 产物需要稳定映射关系。
- 当前真实入口拓扑不只包含 `?caseId=` 深链，还包含无 `caseId` 时落到 `home.html`，以及 `login.html` / `admin.html` / `model-config.html` 与共享 `vue-auth-assets` 等正式发布资源。
- 若 dist 结构不冻结，部署、缓存和回滚合同都无法稳定复用。
- `FE-20260411-06` 已明确配置、CDN、`js/auth-runtime.js`、`vue-auth-assets/**` 与 legacy bundle 的边界，因此 dist 结构现在可以冻结成单一口径。

### 7.1 `frontend/dist` 目标目录结构

```text
frontend/dist/
├── index.html
├── home.html
├── login.html
├── admin.html
├── model-config.html
├── report.html
├── config.js
├── config.local.js
├── styles.css
├── css/
│   └── report.css
├── js/
│   ├── config.js
│   ├── auth-runtime.js
│   ├── problem-detail-app.bundle.js
│   ├── home-legacy.bundle.js
│   └── report-app.bundle.js
└── vue-auth-assets/
    ├── login.js
    ├── admin.js
    ├── home.js
    ├── model-config.js
    ├── login.css
    ├── admin.css
    ├── home.css
    ├── model-config.css
    ├── shared-runtime-dom.esm-bundler.js
    ├── shared-_plugin-vue_export-helper.js
    └── version.txt
```

说明：

- 根目录只保留正式公开入口与外置配置，不再把部署方逼到二次拼装目录。
- `js/` 目录下保留 2 个直连复制脚本 `config.js`、`auth-runtime.js` 和 3 个 A 线生成 bundle；具体实现可进一步校正 bundle 内容，但不得改动这些职责边界与入口落点。
- `vue-auth-assets/` 视为整体复制目录，禁止只挑部分文件进入 dist。

### 9.2 不算完成的情况

- 只写“输出到 dist”，没有目录结构表。
- 未给出拷贝清单或缺少配置文件落点。
- 只覆盖详情深链，没有对齐当前首页与认证资源拓扑。
- 401、428 或 AI 配置门禁跳到登录页 / 模型配置页时，dist 中缺页或缺资源仍被判定为完整。
- 不同入口页或资源位置仍存在多套口径。

## 11. 失败/停止条件

- dist 结构与 build 输入输出合同冲突。
- 无法明确某些静态资源是否应进入 dist。
- 部署侧要求的必要文件不在清单中。
- 若实现方案要求新增第二个公开详情入口或把正式入口页放到 dist 根目录之外，必须停止并升级主记录。

## 2. 任务目标

- 明确第三方依赖、vendor 与配置文件在 build 产线中的处理方式。
- 冻结 `config.js` / `config.local.js` 外置策略。

## 3. 当前事实

- 旧 `frontend` 同时存在业务脚本、配置脚本与第三方依赖。
- 配置文件往往承载部署环境差异，不能简单打进业务 bundle。
- vendor 与配置策略不冻结，后续容易出现环境耦合、回滚困难和缓存污染。
- 现状已经形成四类不同资产：外置配置、HTML 直接依赖的 CDN、`frontend-vue` 已产出的 `vue-auth-assets/**`、以及 A 线 legacy bundle 范围。
- `login/admin/model-config` 依赖 `js/auth-runtime.js` 与 `vue-auth-assets/**`，`index/home/report` 还依赖 `marked` / `dompurify` / `mermaid` 等外链，说明 vendor 策略不能“一刀切全部内联”。

## 4. In Scope

## 5. Out Of Scope

## 7. 实施说明

### 7.1 配置外置策略

| 资产 | 固定策略 | 说明 |
| --- | --- | --- |
| `frontend/config.js` | 原样复制并保持外置 | 默认环境配置，部署环境可直接替换 |
| `frontend/config.local.js` | 原样复制并保持外置 | 本地 / 覆写配置，不进入业务 bundle |
| `window.APP_CONFIG` | 保持全局直读入口 | 不允许改成 bundle 私有变量 |
| `frontend/js/config.js` | 原样复制，继续由详情 / 首页入口直连 | 常量与任务配置脚本，不并入 A 线 legacy bundle |
| `frontend/js/auth-runtime.js` | 原样复制，继续由 HTML 直连 | 登录、管理、模型配置页与 online 入口链共用，不并入 legacy bundle |

### 7.2 第三方依赖处理策略

| 依赖 / 资产 | 当前入口 | 固定策略 | 备注 |
| --- | --- | --- | --- |
| `marked@12` CDN | `index.html`、`home.html`、`report.html` | 保持外链 | 不进入 A 线首批 vendor 包 |
| `dompurify@3` CDN | `index.html`、`home.html`、`report.html` | 保持外链 | 同上 |
| `mermaid@10` CDN | `index.html`、`report.html` | 保持外链 | 流程图链路仍走外链，不做二次 vendor 化 |
| `frontend/vue-auth-assets/*.js` | `home/login/admin/model-config` | 原样复制 | 由 `frontend-vue` 产出，A 线不重打 |
| `frontend/vue-auth-assets/*.css` | `home/login/admin/model-config` | 原样复制 | 与对应 HTML 入口成套复制 |
| `frontend/vue-auth-assets/shared-*.js` | `home/login/admin/model-config` | 原样复制 | `modulepreload` 依赖，不能缺失 |
| `frontend/vue-auth-assets/version.txt` | `vue-auth-assets` | 原样复制 | 当前产物版本指纹文件，保留发布证据价值 |
| `frontend/styles.css`、`frontend/css/report.css` | 所有正式入口 / 报告页 | 原样复制 | 不并入首批 vendor 或 CSS bundle |

### 7.3 进入 A 线 bundle 的依赖边界

| 类别 | 是否进入 A 线 bundle | 说明 |
| --- | --- | --- |
| legacy 业务 JS / core modules | 是 | 详见 `FE-20260411-02` |
| 外置配置 | 否 | 保持独立替换能力 |
| `js/config.js` | 否 | 保持入口级直连脚本，不与部署环境配置脚本混写 |
| `js/auth-runtime.js` | 否 | 保持多入口直连脚本 |
| CDN 外链 | 否 | 维持现状，避免把 vendor 策略和构建稳定性绑死 |
| `vue-auth-assets/**` | 否 | 属于 `frontend-vue` 产物链，只复制 |

### 7.4 依赖与配置边界合同

| 场景 | 固定合同 |
| --- | --- |
| 换环境 | 仅替换 `config.js` / `config.local.js`，不重写 bundle |
| 回滚 | bundle、`vue-auth-assets/**`、外置配置可分层回退，但正式部署包必须同时携带正确版本 |
| 线上排障 | 允许直接检查外置配置与 CDN 命中；不接受“配置已被混进 bundle 无法确认”的状态 |
| A 线 build 失败兜底 | 若仅轻混淆阶段出问题，可回退到 minify + 原有外链 / 外置配置口径 |

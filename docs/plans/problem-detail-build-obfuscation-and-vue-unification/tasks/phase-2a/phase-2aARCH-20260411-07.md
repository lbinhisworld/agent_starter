- 一旦误入业务重写，B 线风险会与 A 线工程化风险互相绑定，专项节奏会失控。
- 主记录 §3、§9 已经明确 B 线定位，但仍需要在 2A phase 首卡再次写死，避免后续 FE / BE 卡各自演化出第二套理解。

## 9. 验收边界

### 9.1 完成结果

- 已按固定矩阵对 A 线真实产物完成 smoke。
- 运行时证据有截图、关键页面命中与异常记录，不只是一句“本地跑通”。
- 若存在问题，已能对应到失败分级与是否阻断发布。

### 9.2 不算完成的情况

- 只验证 build 成功，没有验证运行时行为。
- 只测详情深链，不测首页、登录、模型配置、报告与 `task1` / `task7` 高风险链。
- 没有把异常写入固定模板，导致 owner 无法据此做 go/no-go 判断。

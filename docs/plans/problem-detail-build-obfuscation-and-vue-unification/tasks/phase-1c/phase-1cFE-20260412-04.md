# FE-20260412-04 · 固化 dist copy and external assets

## 1. 任务元数据

- 任务编号：`FE-20260412-04`
- Phase：`1C`
- owner：`frontend`
- 优先级：`P1`
- 状态：`completed`

## 2. 任务目标

- 把 `frontend/dist` 中 copy / external 资产链真正固化到执行流程里。
- 保证入口 HTML、外置配置、`auth-runtime.js`、`vue-auth-assets/**` 与其它非 bundle 资产不会在发布时漏拷贝。
- 让部署同学面对的是一个完整且可直接发布的 dist 目录，而不是“还差一批手工资源”。

## 3. 当前事实

- `FE-20260411-06` 与 `FE-20260411-07` 已冻结 vendor / config 外置策略和 dist 目录结构。
- 旧工程最容易出问题的不是 bundle 本身，而是外置配置、页面入口和共享资源在 copy 链路中遗漏。
- A 线生产执行若缺少 copy/external 固化，后续 smoke 结果会高度不稳定。

## 4. In Scope

- dist copy 清单真正落地。
- external 资产与外置配置落位规则。
- copy 后目录校验与缺件失败机制。

## 5. Out Of Scope

- CDN vendor 本地化。
- 生产 CDN / Nginx 配置。
- B 线统一工程调整。

## 6. 前置依赖

- `FE-20260412-01`
- `FE-20260411-06`
- `FE-20260411-07`

## 7. 实施说明

1. [build-dist.mjs](/Users/tzknow/Documents/do1/workspace/do1_smart_cto/frontend/scripts/build-dist.mjs) 已把 copy 链固定为：入口 HTML、`config.js` / `config.local.js`、`js/config.js`、`js/auth-runtime.js`、`styles.css`、`css/report.css` 与 `vue-auth-assets/**` 的复制，加上 3 个 legacy bundle 的生成。
2. 目录结构仍严格遵守 `FE-20260411-07`，未改动 dist 根目录拓扑；`find frontend/dist -maxdepth 3 -type f | sort` 已能稳定得到完整发布集合。
3. 已把“关键文件缺失即失败退出”真正固化到 runner：源文件 / 目录缺失会在 copy 阶段被 `ensureSourceFile` / `ensureSourceDir` 阻断，构建完成后还会通过 `requiredDistFiles + HTML local reference` 校验再做一次完整性检查。
4. external 口径继续保持为“CDN 外链不本地化、`vue-auth-assets/**` 只复制不重打、外置配置不并入 bundle”，未越过 `FE-20260411-06` 的分类边界。

## 8. 交付物

- 固化后的 dist copy / external 资产链
- 关键文件校验规则
- dist 目录关键路径清单

## 9. 验收边界

### 9.1 完成结果

- `frontend/dist` 中 copy / external 资产链可重复执行且不依赖人工补件。
- 入口 HTML、配置、共享资源和外链依赖口径与 Phase 1A 合同一致。
- 关键文件缺失会在构建阶段被阻断，而不是拖到部署后才发现。

### 9.2 不算完成的情况

- 只固化 bundle，没有固化 copy / external 资源。
- dist 目录仍需人工补拷配置、首页或 `vue-auth-assets/**` 才能使用。
- 目录结构与 `FE-20260411-07` 合同不一致。

## 10. 必备证据

- 文档或产物文件：copy 清单、关键路径清单、失败退出规则
- 命令或检查入口：dist 目录树、关键资源存在性检查
- 最小回归项：`home.html`、`login.html`、`model-config.html`、`report.html` 与 `vue-auth-assets/**` 在 dist 内完整可见
- 若适用则写 diff / fixture / 运行时证据：copy 前后目录对照

## 11. 失败/停止条件

- 无法用固定规则解释 external 资产去向。
- copy 链需要改动公开入口路径或外置配置语义。
- 缺件校验无法在构建阶段暴露关键资源遗漏。

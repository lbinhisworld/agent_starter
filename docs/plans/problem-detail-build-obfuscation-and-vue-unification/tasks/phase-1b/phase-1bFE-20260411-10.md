### 7.1 A 线失败分级表

| 等级 | 典型问题 | 是否立即回滚 | 默认动作 |
| --- | --- | --- | --- |
| `L1-观察级` | 文案小漂移、非关键 warning、可观察但不阻断的样式细节偏差 | 否 | 记录问题，继续完成本轮 smoke，纳入残余风险 |
| `L2-混淆级` | 轻混淆引起的局部运行异常，但上一稳定 build/minify 包可用 | 视影响面，通常是 | 优先回退轻混淆影响；若无法快速剥离，则整包回滚到上一稳定包 |
| `L3-发布级` | HTML / JS / 配置混批、资源 404、`vue-auth-assets` 缺失、版本命中不一致 | 是 | 立即整包回滚，停止当前批次继续验收 |
| `L4-阻断级` | 详情深链打不开、登录 / 模型配置链断裂、聊天发送失败、关键任务动作失败 | 是 | 立即整包回滚，并标记当前批次 fail |
| `L5-流程级` | 无法确认命中批次、无回滚路径、证据不足、deploy 合同无法执行 | 是 | 停止上线 / 停止验收，不得宣称通过 |

### 7.2 默认回滚动作

| 等级 | 默认动作 | 记录要求 |
| --- | --- | --- |
| `L1-观察级` | 不回滚；记录在运行时证据与验收记录的残余风险 | 记录现象、影响面、是否待修复 |
| `L2-混淆级` | 优先回到“仅 build + minify”的上一稳定包；若无法确认，仅执行整包回滚 | 记录触发点、是否确认为轻混淆导致 |
| `L3-发布级` | 立即整包回滚到上一稳定发布包 | 记录回滚批次、回退后复验结果 |
| `L4-阻断级` | 立即整包回滚 + 当前批次 fail | 记录阻断路径、用户影响面、回滚耗时 |
| `L5-流程级` | 停止当前批次，不进入通过结论 | 记录缺失的合同 / 证据 / 能力项 |

### 7.3 失败判定门槛

| 现象 | 默认分级 |
| --- | --- |
| `SmartCto.*`、storage key、`message.type` 漂移 | `L2` 起步，通常升到 `L3` |
| `index.html?caseId=` 无法打开 | `L4` |
| `home.html`、`login.html`、`model-config.html` 任一正式入口打不开 | `L4` |
| `config.js` / `config.local.js` 未命中或命中错环境 | `L3` |
| `vue-auth-assets/version.txt` 与当前批次不一致 | `L3` |
| 浏览器无法确认命中的 `release_id` | `L5` |
| `task1` 高风险 smoke 失败但其它入口正常 | `L2` 或 `L4`，视是否阻断主链 |

### 7.4 失败后最小记录要求

| 字段 | 最低要求 |
| --- | --- |
| 失败等级 | `L1`–`L5` |
| 对应 smoke 编号 | 如 `S03` / `S10` |
| 触发页面 | 详情 / 首页 / 登录 / 模型配置 / 报告 |
| 现象描述 | 1 句说明 |
| 浏览器命中证据 | 必填 |
| 是否回滚 | `yes/no` |
| 回滚目标批次 | 若回滚则必填 |
| 回滚后复验 | 若回滚则必填 |

## 9. 验收边界

### 9.1 完成结果

- 已明确哪些问题回滚混淆、哪些回滚 build、哪些停止当前批次。
- 失败出现后不需要临场重新定义处理路径。

### 9.2 不算完成的情况

- 只有“有问题就回滚”的笼统说法。
- 没有按问题类型区分动作。
- 分级表不能指导实际排障和记录。

## 10. 必备证据

- 文档或产物文件：失败分级表、回滚动作表、记录要求
- 命令或检查入口：
  - `ARCH-20260411-06` deploy / rollback 合同
  - `FE-20260411-08` 运行时证据模板
  - `FE-20260411-09` smoke 矩阵
- 最小回归项：能用分级表解释一类混淆异常和一类部署异常的默认动作

## 11. 失败/停止条件

- 失败分级与主记录风险表冲突。
- 回滚动作无法落实到 deploy 合同。
- 无法区分“问题可观察但不回滚”和“必须立即回滚”的门槛。
- 若执行人无法将失败映射到 `L1`–`L5` 中任一级，必须停止当前批次并升级人工。

### 7.2 字段解释

| 字段 | 最低要求 |
| --- | --- |
| 验收编号 | 唯一编号，便于在主记录中引用 |
| 发布批次 | 与运行时证据中的 `release_id` 保持一致 |
| 关联运行时证据 | 不可缺失，避免验收结论悬空 |
| 总结论 | 必填，只能是 `pass / conditional-pass / fail` |
| 失败分级 | 若非 `pass`，必须引用 `L1`–`L5` |
| 残余风险 | 即使为空也要明确写 `none` |
| 主记录回写摘要 | 必填，便于回写专项 `README.md` §13 |

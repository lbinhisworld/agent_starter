# FE-20260411-23 · 定义 B 线回退与残余风险记录模板

## 1. 任务元数据

- 任务编号：`FE-20260411-23`
- Phase：`3`
- owner：`frontend`
- 优先级：`P1`
- 状态：`completed`

## 2. 任务目标

- 定义 B 线切换后的回退条件与残余风险记录模板。
- 固定切回触发器、阻塞项、未验收项和残余风险的记录格式。
- 让切换失败时能够快速切回并留下可追溯记录。

## 3. 当前事实

- 灰度切换后必须有明确的切回条件，否则即使发现漂移也可能延误处置。
- 仅写“有问题就回滚”不足以支撑切换治理。
- 残余风险和未验收项必须被显式记录，才能支持后续拆批和延期判断。

## 4. In Scope

- 切回条件
- 残余风险、阻塞项、未验收项记录模板
- 与灰度规则和 readiness gate 的衔接

## 5. Out Of Scope

- 切回技术实现
- 监控告警系统
- 长期全量切换策略

## 6. 前置依赖

- `ARCH-20260411-08`
- `FE-20260411-22`

## 7. 实施说明

1. 定义哪些问题触发立即切回，哪些问题只记录为残余风险继续观察。
2. 把切回条件、残余风险、阻塞项、未验收项拆成独立字段记录。
3. 要求每次灰度或切换结论都能回链到该模板。
4. 让后续延期、拆批与升级人工基于统一记录作判断。

### 7.1 立即切回触发器

| 级别 | 触发信号 | 默认动作 |
| --- | --- | --- |
| P0 | 同 URL fallback 失效，无法在当前 `index.html?caseId=` 下回到 legacy | 立即切回 |
| P0 | selector / DOM 出现影响首批范围正确性的关键漂移 | 立即切回 |
| P0 | 401 / 404 / 428 / `AI_CONFIG_REQUIRED` / owner isolation 语义漂移 | 立即切回并升级 backend / architect |
| P1 | 个别样式漂移但不影响首批范围正确性 | 先记录为残余风险，按灰度批次继续观察或降级批次 |
| P1 | 单个 fixture 未验收但未进入当前灰度覆盖范围 | 记为未验收项，不自动触发切回 |

### 7.2 残余风险记录模板

| 字段 | 固定要求 |
| --- | --- |
| 批次 | `L1` / `L2` / `L3` |
| readiness 引用 | 回链 `ARCH-20260411-08` 结论 |
| 灰度规则引用 | 回链 `FE-20260411-22` |
| 是否切回 | `yes` / `no` |
| 切回触发器 | 若切回则必填 |
| 阻塞项 | 当前仍阻塞继续灰度的事项 |
| 未验收项 | 尚未完成但未必阻塞当前批次的事项 |
| 残余风险 | 继续保留观察的问题 |
| owner | 责任主位 |
| 下一动作 | `rollback` / `fix` / `hold` / `continue` / `escalate` |

### 7.3 阻塞项 / 未验收项 / 残余风险的判定边界

| 类别 | 固定解释 |
| --- | --- |
| 阻塞项 | 不解决就不能继续当前灰度或进入下一批次的问题 |
| 未验收项 | 尚未完成验证，但当前批次尚未用到或尚未覆盖到的项 |
| 残余风险 | 已知问题被接受为暂时继续观察，但必须记录 |

### 7.4 最小记录样式

```text
批次：L2
readiness：ready_for_gray
是否切回：yes
切回触发器：同 URL fallback 失效
阻塞项：
- fallback 无法在当前 index.html?caseId= 下恢复 legacy
未验收项：
- pd-online-task11-core-business-object-modify 尚未完成最新一轮 DOM 对照
残余风险：
- task10 侧栏汇总 token 样式存在轻微偏移，未影响逻辑
下一动作：rollback
```

### 7.5 与后续拆批 / 延期的关系

1. 若存在阻塞项，默认不允许进入下一灰度批次。
2. 若只存在未验收项，需结合 `ARCH-20260411-09` 的拆批规则决定是否延期。
3. 若只存在残余风险，需在每次批次结论里显式回写，不允许口头带过。

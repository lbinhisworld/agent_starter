# ARCH-20260411-09 · 定义双轨专项拆批与延期规则

## 1. 任务元数据

- 任务编号：`ARCH-20260411-09`
- Phase：`3`
- owner：`architect owner`
- 优先级：`P1`
- 状态：`completed`

## 2. 任务目标

- 定义双轨专项的拆批与延期规则。
- 明确 A 线可以先单独关账，B 线继续存续。
- 避免 A 线与 B 线互相绑死，导致整体无法收口。

## 3. 当前事实

- A 线和 B 线虽然相关，但成熟度和交付节奏不同。
- 若没有拆批与延期规则，任何一条线未完成都可能拖住另一条线的收口。
- 残余风险、未验收项和切换准备度都需要被纳入延期判断。

## 4. In Scope

- 双轨拆批规则

- A 线单独关账、B 线继续存续的边界

## 5. Out Of Scope

- 单个 FE/BE 子任务重排
- 实际排期管理工具
- 人员分工调整

## 7. 实施说明

1. 明确 A 线与 B 线可以独立评估、独立关账，不要求同步完成。
2. 定义哪些情况允许拆批，哪些情况必须延期并升级人工。
3. 把延期判断与残余风险、阻塞项、未验收项、readiness gate 结果关联起来。
4. 让专项后续可以按稳定度推进，而不是被最慢链路整体拖住。

### 7.1 双轨关账规则

| 线路 | 独立关账条件 | 允许在另一条线未完成时关账吗 |
| --- | --- | --- |
| A 线 | Phase 1A + 1B 合同完成，A 线 deploy / smoke / rollback / 运行时证据稳定 | 允许 |
| B 线 | Phase 2A + 2B + 3 合同完成，且 readiness / 灰度 / 切回模板完整 | 允许 |
| 专项整体 | A 线与 B 线都达到各自关账条件，或明确按拆批规则转入“ A 已关账 / B 持续存续 ”状态 | 允许分批，不要求同日完成 |

### 7.2 允许拆批的情况

| 情况 | 允许动作 | 固定口径 |
| --- | --- | --- |
| A 线已稳定，B 线仍 `not_ready` | A 线先关账，B 线继续作为迁移专项存续 | 最典型拆批情形，禁止因 B 线未 ready 否决 A 线收口 |
| A 线已稳定，B 线仅 `ready_for_preparation` | A 线关账；B 线继续补灰度证据 | 允许 |
| B 线进入 L1/L2 灰度，但仍有残余风险 | A 线维持已关账；B 线按灰度批次继续 | 允许，但必须保留 B 线进行中状态 |
| B 线发现问题需回退到 legacy | A 线不受影响；B 线回到 `not_ready` 或 `ready_for_preparation` | 允许，且不得把 A 线一起打回未关账 |

### 7.3 必须延期并升级人工的情况

1. A 线本身不稳定，导致 `frontend/dist` 发布拓扑、默认入口、登录 / 模型配置 / 详情链路无法保证。
2. B 线问题已经反咬 A 线发布拓扑、同 URL 入口或后端 online 合同，责任主位不清。
3. 阻塞项无法归类为 A 线或 B 线单边问题，且继续推进会造成两条线口径冲突。
4. readiness 结论、灰度记录和切回模板互相矛盾，无法判断当前到底能否继续灰度。

### 7.4 延期判断字段

| 字段 | 固定要求 |
| --- | --- |
| 当前线路 | `A` / `B` / `A+B` |
| 当前状态 | `closed` / `in_progress` / `delayed` |
| readiness 引用 | 若是 B 线，必填 |
| 阻塞项 | 必填 |
| 未验收项 | 若有必填 |
| 残余风险 | 若有必填 |
| 是否升级人工 | `yes` / `no` |
| 下一批次 | 继续、延期或关账说明 |

### 7.5 典型判定示例

| 场景 | 结论 |
| --- | --- |
| A 线 smoke 稳定，B 线双渲染仍有 P0 差异 | A 线可关账；B 线延期并继续修复 |
| A 线 smoke 不稳定，B 线 readiness 已通过 | 不允许宣布专项整体收口；优先修 A 线 |
| B 线 L2 灰度中发现同 URL fallback 失效 | B 线立即回退并延期；A 线保持已关账 |

## 9. 验收边界

### 9.1 完成结果

- 已明确 A 线可以先单独关账，B 线继续存续。
- 已明确何时允许拆批、何时必须延期，不再把两条线绑死。

### 9.2 不算完成的情况

- 两条线仍被写成必须同步收口。
- 没有延期条件或只能靠主观判断。
- 拆批规则无法与残余风险和 readiness gate 联动。
- 无法明确说明“A 已关账 / B 持续存续”是不是合法状态。

## 10. 必备证据

- 仍无法回答“双轨中一条线先关账是否允许”。

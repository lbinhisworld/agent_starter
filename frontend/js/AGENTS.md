# Folder: frontend/js

## 地位

前端业务脚本核心目录，承载问题跟进主流程、任务执行状态与本地持久化能力。

## 职责

- 管理数字化问题跟进流程中的任务状态与会话数据。
- 提供任务执行所需的上下文组装与结构化数据写入能力。
- 统一封装本地存储读写（含 IndexedDB 适配）以保障聊天记录与任务数据一致性。

## 约束

- 任务会话类数据（如 `coreBusinessObjectSessions`）写入与读取必须走同一存储适配通道，避免“写入成功但读取为空”的状态分叉。
